문서 템플릿
층
수정 모드 — 표시를 누르면 종류를 바꾸거나 지울 수 있고, 글자를 끌어 고르면 새 표시나 메모를 달 수 있습니다. 설명 상자와 메모는 글을 누르면 치는 대로 바로 바뀌고, 꼬리표를 누르면 설명 종류를 바꿀 수 있습니다. 원문 글자는 바뀌지 않습니다.
원문은 고치지 않고 그 위에 템플릿별 표시·설명·번역·내 메모 층만 얹습니다. 표시와 설명은 LLM 이 만든 문서 파일(documents/*.js)에서 오고, 고친 내용은 이 브라우저에만 저장되니 "내보내기"로 백업하세요. 새 문서를 만드는 법은 README 를 보세요.
